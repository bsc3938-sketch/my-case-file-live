# MY CASE FILE 실시간 발표형

## 실제 공개 링크를 만들기
이 ZIP은 완성된 웹앱 소스이며, 공개 주소는 아직 생성되지 않았습니다.

1. GitHub에 새 저장소를 만들고 이 폴더의 파일들을 업로드합니다. (ZIP 파일 자체가 아닌 압축 해제한 파일)
2. https://render.com 에 가입해 New > Web Service에서 해당 GitHub 저장소를 연결합니다.
3. Build Command: `npm install`, Start Command: `npm start`, Runtime: Node
4. Environment에 `PRESENTER_KEY`라는 이름으로 충분히 긴 **비밀 비밀번호**를 설정합니다.
5. Deploy 후 Render에서 생성된 HTTPS 주소를 확인합니다.

## 주소
- 관객에게 공유: `https://실제-주소.onrender.com/`
- 진행자 전용: `https://실제-주소.onrender.com/?presenter=1`
  진행자 링크로 접속해 비밀번호를 입력하세요. 비밀번호를 관객에게 공유하지 마세요.

## 동작
- 관객 화면에는 기존 MY CASE FILE 프레임/헤더가 있고 조작 버튼은 없습니다.
- 진행자가 장면을 넘기면 인터넷으로 연결된 관객 화면도 바뀝니다.
- 늦게 입장한 관객은 현재 장면부터 시작합니다.
- 관객의 오디오 재생은 꺼져 있습니다. 진행자 음성을 화상회의로 전달하거나 별도 방송 송출을 이용하세요.
- 현재는 서버 하나당 발표 세션 하나입니다. 여러 발표자가 동시에 조작하지 마세요.
- 무료 호스팅은 비활성 상태에서 잠들거나 재시작될 수 있으며 재시작 시 첫 장면으로 돌아갈 수 있습니다.
- 실시간 접속에는 서버 호스팅이 필요합니다. 단순 정적 파일 업로드만으로는 동작하지 않습니다.
